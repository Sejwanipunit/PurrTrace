00

Brand personality

PawTrace borrows MindMarket's playful, human-centered warmth — but tunes it for emotional range. The same app must feel reassuring at 11pm when a dog is missing, and joyful the morning it comes home.

🤝 Warm, not clinical

Rounded forms, soft cream surfaces, friendly copy. This is a neighbor helping, not a database.

🌱 Hopeful by default

Green leads everything. Even a "Lost" listing frames the goal: getting home.

⚡ Clear under stress

Coral and high contrast for urgent states. When it matters, the interface gets calm and direct.

01

Four brand families on warm neutrals. Sprout carries the brand and primary actions; Sunbeam highlights and draws the eye; Lagoon signals trust, info, and calm resolution; Coral is reserved for the Lost state and genuine urgency.

import androidx.compose.material3.lightColorScheme
import androidx.compose.runtime.Composable

  primary            = Sprout500,
  onPrimary          = Color.White,
  primaryContainer   = Sprout100,
  onPrimaryContainer = Sprout900,
  secondary          = Lagoon500,        // trust / info
  onSecondary        = Color.White,
  tertiary           = Sun400,           // highlight
  onTertiary         = Bark900,
  error              = Coral500,         // Lost / destructive
  onError            = Color.White,
  errorContainer     = Coral50,
  background         = Cream,
  onBackground       = Bark900,
  surface            = Color.White,
  onSurface          = Bark900,
  surfaceVariant     = Sand,
  onSurfaceVariant   = Bark700,
  outline            = BorderTan,

@Composable
fun PawTraceTheme(content: @Composable () -> Unit) {
  MaterialTheme(
    colorScheme = PawLight,
    typography  = PawType,
    shapes      = PawShapes,
    content     = content,
  )
}
07

Voice & copy

Words are design material. PawTrace speaks like a calm, helpful neighbor — plain verbs, sentence case, and never vague when it matters most.

01

Name the action, not the system

"Report a sighting," not "Submit form." The button that says "Mark as reunited" produces a toast that says "Reunited 🎉".

02

Errors guide, they don't apologize

"We couldn't find that area — try a nearby landmark," not "Oops! Something went wrong."

03

Empty states invite action

"No pets reported nearby — that's good news. Be the first to help if something changes."
